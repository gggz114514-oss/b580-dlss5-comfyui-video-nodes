# 便携运行包

v0.2.0-pre 包含29个运行包分片和 release-assets.json。安装器按其中的固定版本与 SHA256 获取并校验附件。

安装完成后的用法：把节点仓库放入 ComfyUI/custom_nodes，双击 Install.bat，重启 ComfyUI。运行包安装到节点目录的 `.runtime`，节点自动发现，无需填写本机开发路径，也不需要向 ComfyUI 的 Python 安装 Torch 或 Triton。可选 config.json / NR_COMFY_CONFIG 仍支持覆盖运行位置和任务目录。

附件分成64MiB以内的小分片，安装器逐片校验 SHA256，再重组为 Python、Triton 工具链、后端三份 ZIP；对重组ZIP再次校验后解压。分片只改变传输方式，ZIP内容不变。模型由安装器从固定的社区参考版本获取，校验归档及 DLL 后静态提取资源；不执行该 DLL。本仓库不把该资源宣称为开源授权权重，也不在自己的附件中重新分发原始权重。上游获取不可用或校验不符时安装停止，不换用未验证版本。

预编译的三个主机辅助模块随包提供。Triton 的 driver、compiler、extension_utils 三处引用全部接到经过源码与二进制哈希验证的加载器。精确后端继续检查模型源码、内核、运行时和设备配置；未知配置报错，不现场编译、不通过修改预期指纹绕过。

缓存分组和模型配置中的安装位置由 relocate.py 生成。搬动整个节点目录后，需用 `.runtime/python/python.exe -B -X utf8 .runtime/relocate.py` 重新生成路径。不要单独挪动其中的子目录。

目前验证目标是 Windows x64 的 Intel Arc B580。精确缓存还约束驱动与设备指纹；便携化解决依赖和路径分发，不等于任意显卡或驱动兼容。不同硬件需要新的验证和对应缓存。

已完成的便携验证：精确单 NR，864×480、243帧、24fps及音频，完整独立解码通过；worker Python 与五个主要运行库均来自便携目录，运行期间未编译，记录的CPU像素传输为零。快速2×SR+FG也通过485帧验证。后续从 ZIP 在独立中文路径安装，精确1×AA+FG和快速单NR均完成完整视频并独立解码，音轨保留。此测试使用本地附件及在线模型下载，不代表已在另一台机器测试。
